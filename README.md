# 3D Printing Cost Calculator (Java)

Sistema desenvolvido em Java para auxiliar na precificação de peças de manufatura aditiva (Impressão 3D). O software calcula custos operacionais com base em variáveis de insumo (filamento) e consumo energético.

## 🚀 Tecnologias Utilizadas
* **Java 17** (Linguagem Core)
* **POO** (Encapsulamento e Métodos)
* **Console I/O** (Entrada e Saída de dados)

## ⚙️ Funcionalidades
* Cálculo de custo por grama de material (PLA/ABS/PETG).
* Conversão de consumo elétrico (Watts para kWh) e cálculo de custo energético baseado no tempo de impressão.
* Geração automática de preço de venda sugerido.

## 📦 Como rodar
1. Clone o repositório.
2. Compile o arquivo `Main.java`.
3. Execute no terminal e insira os dados solicitados.
