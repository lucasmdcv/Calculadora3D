# 3D Printing Cost Calculator (Java + SQLite) 🖨️

Sistema desenvolvido em Java para precificação de peças de manufatura aditiva. O projeto evoluiu de uma ferramenta de console simples para uma aplicação com persistência de dados.

## 🚀 Tecnologias
* **Java** (Lógica e POO)
* **SQLite** (Banco de dados relacional leve)
* **JDBC** (Driver de conexão Java-Banco)

## ⚙️ Funcionalidades
* ✅ Cálculo automático de custo (Filamento + Energia).
* ✅ Persistência de dados: Salva o histórico de orçamentos automaticamente.
* ✅ Consulta: Permite visualizar o histórico de impressões salvas.
* ✅ Tratamento de Erros: Sistema blindado contra digitação de vírgulas ou textos inválidos.

## 📦 Como rodar
1. Baixe o projeto.
2. Certifique-se de ter o arquivo `sqlite.jar` na pasta.
3. Compile:
   `javac *.java`
4. Execute (Windows):
   `java -cp ".;sqlite.jar" Main`
